## 핵심 요약

이 장은 디지털 논리 설계의 출발점인 조합논리를 다룬다. 조합논리는 현재 입력만으로 출력이 결정되는 회로이며, 과거 상태를 저장하지 않는다는 점에서 [[06 순차논리 설계]]의 순차논리와 구분된다. 입력-출력 관계를 진리표로 정의하고, Boolean algebra와 표준형, Karnaugh map을 이용해 더 단순하고 빠른 회로로 구현하는 것이 핵심이다.

중요한 흐름은 다음과 같다.

- 문제를 입력과 출력으로 정의한다.
- 진리표를 만든다.
- Boolean 식을 canonical form 또는 최소화된 SOP/POS로 표현한다.
- NAND/NOR, MUX, ROM, PLA/PAL 같은 구현 대상으로 옮긴다.
- 지연과 hazard가 실제 회로 동작에 영향을 줄 수 있음을 확인한다.

## 조합논리의 의미

조합논리는 출력이 오직 현재 입력의 함수인 회로다. 예를 들어 등가 비교 회로는 두 입력이 같은지 판단하고, tally 회로는 입력 중 1의 개수를 세며, 특정 4비트 수가 2, 3, 5로 나누어지는지 판정하는 회로도 조합논리 문제로 모델링할 수 있다.

조합논리 설계에서 가장 먼저 할 일은 회로를 그리는 것이 아니라 문제의 입출력을 분명히 하는 것이다. 입력 비트가 무엇을 의미하는지, 출력이 어떤 조건에서 1이 되어야 하는지 정리하면 진리표가 만들어지고, 진리표는 해당 Boolean function의 유일한 동작 서명이 된다.

## 기본 게이트와 완전 함수 집합

기본 논리 연산은 NOT, AND, OR이며, NAND와 NOR는 각각 단독으로 모든 Boolean function을 구현할 수 있는 universal gate이다. 예를 들어 `X AND Y`는 NAND 뒤에 NAND를 한 번 더 써서 보수 반전을 제거할 수 있고, OR도 De Morgan 법칙을 통해 NAND 또는 NOR 네트워크로 변환할 수 있다.

XOR와 XNOR는 비교기, 덧셈기 등에서 자주 등장하지만 기본 게이트보다 구현 비용이 큰 경우가 많다. 따라서 식을 최소화할 때 XOR를 사용한 표현이 논리적으로 간단해 보여도, 실제 게이트 수나 지연 면에서는 항상 유리하다고 단정하면 안 된다.

## Boolean Algebra

Boolean algebra는 집합 `B = {0, 1}`과 두 이항 연산 `+`, `.` 및 단항 연산 보수 `'`를 기반으로 한다. 디지털 논리에서는 `+`가 OR, `.`가 AND, `'`가 NOT에 대응된다.

반드시 익숙해야 할 법칙은 다음과 같다.

- 항등 법칙: `X + 0 = X`, `X . 1 = X`
- 영/일 법칙: `X + 1 = 1`, `X . 0 = 0`
- 멱등 법칙: `X + X = X`, `X . X = X`
- 보수 법칙: `X + X' = 1`, `X . X' = 0`
- 결합/교환 법칙: 항의 순서와 묶음이 결과를 바꾸지 않는다.
- 분배 법칙: `X(Y + Z) = XY + XZ`, `X + YZ = (X + Y)(X + Z)`
- 흡수 법칙: `X + XY = X`, `X(X + Y) = X`
- De Morgan 법칙: `(X + Y + ...)' = X'Y'...`, `(XY...)' = X' + Y' + ...`

Duality도 중요하다. 어떤 식에서 `+`와 `.`를 서로 바꾸고 `0`과 `1`을 서로 바꾸면 dual 식이 된다. Boolean algebra에서 하나의 정리가 성립하면 그 dual도 성립하므로, 한쪽 법칙을 알면 대응되는 법칙을 함께 얻는다.

## Boolean 식의 증명과 단순화

Boolean 식은 대수 법칙을 이용해 다시 쓰면서 증명하거나 단순화한다. 예를 들어 `XY + XY' = X(Y + Y') = X`와 같이 보수 법칙과 항등 법칙을 적용할 수 있다. 슬라이드의 활동 문제처럼 `(XY) + (YZ) + (X'Z)`에서 consensus 항을 제거하는 과정은 이후 hazard 제거와도 연결된다.

회로 단순화는 단순히 게이트 수를 줄이는 일이 아니라, 팬인, 게이트 단계 수, 지연, hazard 가능성을 함께 고려하는 작업이다. 최소 SOP가 항상 실제 구현 최적은 아니며, multi-level logic으로 factoring하면 더 작은 팬인과 더 적은 배선을 얻을 수도 있다.

## 대표 조합논리 예제

### 1-bit Full Adder

Full adder는 입력 `A`, `B`, `Cin`을 받아 `Sum`, `Cout`을 만든다.

- `Sum = A xor B xor Cin`
- `Cout = AB + ACin + BCin`

`Cout`은 세 입력 중 적어도 두 개가 1일 때 1이 되는 majority 함수로 볼 수 있다. Half adder 두 개와 OR 게이트를 조합해 full adder를 만들 수 있고, 여러 full adder를 직렬로 연결하면 2비트 이상의 binary adder가 된다.

### BCD to 7-Segment Display Controller

입력은 4비트 BCD digit이고 출력은 7개의 segment 제어 신호이다. 10진수 0부터 9까지는 정의되어 있지만 10부터 15까지의 BCD 입력은 사용하지 않는 조합이므로 don't-care로 활용할 수 있다. 이 예제는 진리표 작성, don't-care 활용, ROM/PLA/PAL 또는 게이트 구현 선택을 모두 포함하는 좋은 종합 설계 문제다.

## Canonical Form

진리표는 동일한 Boolean function을 유일하게 정의하지만, 식 표현은 여러 개가 가능하다. Canonical form은 표준화된 표현이다.

### Minterm과 SOP

Minterm은 모든 입력 변수가 정확히 한 번씩 등장하는 AND 항이다. 어떤 입력 조합에서 함수가 1이면 그 행에 해당하는 minterm을 만들고, 전체 ON-set의 minterm을 OR로 묶으면 canonical sum-of-products가 된다.

예시 표기:

```text
F(A,B,C) = Sigma m(1,3,5,6,7)
```

이는 인덱스 1, 3, 5, 6, 7의 입력 조합에서 F가 1이라는 뜻이다.

### Maxterm과 POS

Maxterm은 모든 입력 변수가 정확히 한 번씩 등장하는 OR 항이다. 함수가 0인 행에 해당하는 maxterm을 AND로 묶으면 canonical product-of-sums가 된다.

예시 표기:

```text
F(A,B,C) = Pi M(0,2,4)
```

Minterm 인덱스와 maxterm 인덱스는 서로 보완 관계다. ON-set에 없는 입력 조합은 OFF-set에 해당하므로, minterm 표현과 maxterm 표현 사이를 변환할 수 있다.

## 불완전 지정 함수와 Don't-Care

실제 설계에서는 어떤 입력 조합이 절대 발생하지 않거나 출력이 무엇이어도 상관없는 경우가 있다. 이 입력 조합을 don't-care set으로 둔다. 함수는 ON-set, OFF-set, DC-set으로 나뉘며, 이 중 두 집합을 알면 나머지는 전체 입력 공간의 보수로 정해진다.

Don't-care는 최소화 과정에서 1로 써도 되고 0으로 써도 된다. 목적은 더 큰 묶음을 만들어 literal 수를 줄이는 것이다. 단, don't-care를 회로 동작 중 실제로 발생 가능한 값으로 착각하면 안 된다. 실제 회로에서는 결국 0 또는 1로 구현된다.

## Boolean Cube와 Karnaugh Map

Boolean cube는 입력 조합 사이의 adjacency를 시각화하는 방법이다. 두 minterm이 한 변수만 다르면 하나의 차원으로 인접하며, uniting theorem에 따라 하나의 literal을 제거할 수 있다.

Karnaugh map은 Boolean cube를 평면에 펼친 도구이다. Gray code 순서를 사용하므로 인접한 칸은 한 비트만 다르고, 맵의 가장자리도 wrap-around로 인접한다.

K-map 최소화 절차:

1. ON-set의 1을 배치하고 필요하면 don't-care도 함께 표시한다.
2. 1, 2, 4, 8처럼 2의 거듭제곱 크기의 직사각형 묶음을 만든다.
3. 가능한 한 큰 묶음을 선택해 literal 수를 줄인다.
4. 모든 ON-set 1이 적어도 한 번 덮이도록 cover를 선택한다.
5. 각 묶음에서 변하지 않는 변수만 남겨 product term을 만든다.

K-map에서 중요한 감각은 큰 묶음일수록 식이 짧아진다는 것이다. 0-cube는 모든 변수를 포함한 minterm이고, 1-cube는 literal 하나가 줄어든 항, 2-cube는 두 literal이 줄어든 항으로 해석된다.

## Two-Level과 Multi-Level Logic

Two-level logic은 SOP 또는 POS를 AND-OR, OR-AND 형태로 구현하는 방식이다. 구조가 규칙적이고 분석하기 쉽지만, 큰 함수에서는 OR 게이트의 팬인이 커지고 배선이 많아질 수 있다.

Multi-level logic은 공통 부분식을 묶어 여러 단계로 구현한다. 예를 들어 여러 product term이 공통 literal을 공유하면 factoring을 통해 게이트 수와 배선을 줄일 수 있다. 다만 단계 수가 늘어나면 지연과 hazard 분석이 더 복잡해질 수 있다.

## 지연과 파형 관점

논리식이 같아도 실제 게이트에는 propagation delay가 존재한다. 입력 변화가 여러 경로를 통해 서로 다른 시간에 출력으로 도달하면 순간적으로 잘못된 값, 즉 glitch가 발생할 수 있다. 슬라이드는 파형을 진리표를 옆으로 눕혀 본 것으로 설명하며, 동일한 Boolean function을 구현한 여러 회로가 정적 논리 값은 같아도 시간 응답은 다를 수 있음을 강조한다.
