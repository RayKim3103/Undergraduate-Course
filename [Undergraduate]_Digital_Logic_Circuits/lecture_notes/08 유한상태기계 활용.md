# 08 유한상태기계 활용

관련 노트: [[07 유한상태기계]], [[06 순차논리 설계]], [[04 조합논리 구현 기술]]

## 핵심 요약

이 장은 [[07 유한상태기계]]에서 설계한 FSM을 더 작고 구현하기 쉬운 회로로 바꾸는 방법을 다룬다. 핵심 주제는 state minimization, state assignment, partitioning이다. Fully specified FSM에서는 동등 상태를 비교적 체계적으로 합칠 수 있지만, incompletely specified FSM에서는 호환성과 transitivity 문제가 생긴다. State encoding은 gate 수, product term 수, delay에 직접 영향을 준다.

핵심 메시지:

- State 수를 줄이면 필요한 state bit와 next-state equation 수가 줄 수 있다.
- State bit 수가 최소라고 해서 항상 logic이 최소인 것은 아니다.
- One-hot encoding은 flip-flop을 많이 쓰지만 조합논리를 단순하게 만들 수 있다.
- Programmable logic에 mapping할 때는 입력/출력 pin, product term 수 제한 때문에 FSM partitioning이 필요할 수 있다.

## FSM 최적화 관점

FSM 구현 비용은 여러 encoding 선택에 의해 달라진다.

- State minimization: 동등한 symbolic state를 합친다.
- State assignment: symbolic state에 bit vector를 배정한다.
- Input/output encoding: 외부 신호 표현도 logic complexity에 영향을 줄 수 있다.

적은 state는 적은 flip-flop을 의미할 수 있지만, binary encoding이 복잡한 next-state function을 만들 수도 있다. 반대로 one-hot encoding은 state 수만큼 flip-flop을 쓰지만 각 next-state 식이 단순해지는 경우가 많다.

## 동등 상태의 의미

두 state가 equivalent하다는 것은 모든 가능한 입력 sequence에 대해 동일한 output behavior를 보인다는 뜻이다. Fully specified FSM에서는 다음 조건을 반복적으로 확인해 동등 상태를 찾는다.

- 같은 입력에 대해 같은 출력이 나오는가?
- 같은 입력에 대해 이동하는 next state들이 서로 동등한가?

즉 현재 한 단계 출력만 같다고 충분하지 않다. 이후의 모든 미래 동작까지 같아야 한다.

## Row Matching Method

Row matching method는 state table의 행을 비교해 같은 동작을 하는 state를 합치는 방법이다. 단순한 fully specified FSM에서는 다음 순서로 진행된다.

1. 출력이 다른 state 쌍은 동등할 수 없으므로 분리한다.
2. 출력이 같은 state들을 같은 후보 그룹에 둔다.
3. 각 입력에 대한 next state가 같은 그룹으로 가는지 확인한다.
4. 조건을 만족하지 않는 state를 다시 분리한다.
5. 그룹이 더 이상 변하지 않을 때까지 반복한다.

슬라이드의 sequence detector 예제에서는 처음에 여러 state를 한 집합으로 두고, 출력과 next-state behavior를 기준으로 점점 더 작은 equivalent class로 나눈다.

## Implication Chart Method

Implication chart method는 가능한 state 쌍을 모두 나열하고, 동등할 수 없는 쌍을 표시해 나가는 방식이다.

절차:

1. 모든 state pair를 chart에 배치한다.
2. 출력이 다른 state pair를 즉시 mark한다.
3. 출력은 같지만 next-state pair 중 이미 mark된 쌍을 요구하면 해당 pair도 mark한다.
4. 새 mark가 생기지 않을 때까지 반복한다.
5. mark되지 않은 pair는 equivalent한 state pair로 본다.

이 방법은 row matching보다 체계적이고, 상태 수가 늘어났을 때 누락을 줄일 수 있다. 다만 incompletely specified FSM에서는 "동등" 대신 "compatible" 관계를 더 조심스럽게 다뤄야 한다.

## Incompletely Specified FSM

Fully specified FSM에서는 동등성이 transitive하다. 즉 A와 B가 동등하고 B와 C가 동등하면 A와 C도 동등하다. 그러나 don't-care transition이나 don't-care output이 있는 incompletely specified FSM에서는 compatibility가 항상 transitive하지 않을 수 있다.

따라서 불완전 지정 FSM에서는 단순히 pairwise compatible state를 모두 합치면 안 된다. 합친 후에도 모든 transition과 output choice가 일관되게 정해질 수 있는지 확인해야 한다.

## Edge Detector 예제

Edge detector는 최근 두 입력 값이 달라졌을 때 출력 1을 내는 회로로 볼 수 있다. 이 기능은 이전 입력을 기억해야 하므로 FSM 또는 간단한 register 기반 순차회로로 구현한다.

슬라이드는 "ad hoc solution"이 state 최소는 아니어도 싸고 빠를 수 있음을 보여준다. 즉 FSM 최적화의 목적은 항상 state 수 최소가 아니라 전체 구현 비용, 속도, 설계 단순성의 균형이다.

## State Assignment

State assignment는 symbolic state에 binary code를 배정하는 단계이다. `m`개의 state를 `n`개의 bit로 표현하려면 `2^n >= m`이어야 한다. 가능한 encoding 수는 매우 빠르게 증가하므로 모든 경우를 직접 시도하기 어렵다.

State assignment가 중요한 이유:

- 같은 state diagram도 encoding에 따라 K-map의 1 배치가 달라진다.
- Next-state equation의 literal 수와 product term 수가 달라진다.
- Output equation도 encoding에 따라 단순해질 수 있다.
- Adjacent transition이 많은 state들을 bit adjacency가 가까운 code로 배정하면 식이 단순해질 수 있다.

## State Assignment 전략

### Sequential Encoding

State table에 나온 순서대로 `00`, `01`, `10`, `11`처럼 번호를 붙인다. 쉽고 빠르지만 logic complexity가 좋다는 보장은 없다.

### Random Encoding

임의 배정을 여러 번 시도하고 결과 비용을 비교한다. 상태 수가 많을 때 의외로 좋은 결과를 줄 수 있으며, 슬라이드는 여러 random trial 중 best result를 고르는 방식이 실용적일 수 있음을 언급한다.

### One-Hot Encoding

`n`개 state를 `n`개 flip-flop으로 표현하고, 각 state마다 하나의 bit만 1이 되도록 한다.

장점:

- Encoding과 decoding이 쉽다.
- Next-state logic이 단순해질 수 있다.
- Synchronous Mealy 구현과 잘 맞는 경우가 있다.

단점:

- State 수만큼 flip-flop이 필요하다.
- Flip-flop이 비싼 환경에서는 부담이 된다.

FPGA처럼 flip-flop이 상대적으로 풍부하고 LUT 기반 logic이 중요한 경우 one-hot이 유리할 수 있다.

### Output-Based Encoding

출력 bit 자체를 state bit로 재사용하는 방법이다. 이미 출력이 state를 구분하는 정보를 담고 있다면, 별도 state bit를 만들지 않고 output function을 단순화할 수 있다. 특히 PAL 같은 programmable logic에서는 output encoding을 활용하는 것이 매력적일 수 있다.

## State Assignment Heuristics

좋은 state assignment는 transition이 잦거나 같은 next-state/output pattern을 공유하는 state들을 encoding 공간에서 가깝게 배치하려고 한다. K-map에서 가까운 code는 묶음이 커지기 쉽기 때문이다.

Heuristic의 기본 생각:

- 같은 next state로 가는 state들을 가깝게 둔다.
- 같은 output을 내는 state들을 가깝게 둔다.
- 한 입력 조건에서 서로 전환되는 state들을 인접하게 둔다.
- Reset state는 보통 단순한 code, 예를 들어 `00...0`에 배정한다.

Traffic light controller 예제에서는 gray-like minimum distance encoding이 항상 최선은 아니며, 실제 next-state equation clustering을 봐야 함을 보여준다.

## 3-bit Sequence Detector 예제

3-bit sequence detector에서는 state 간 adjacency 우선순위를 정해 encoding을 선택한다. 어떤 state pair가 같은 입력 조건에서 같은 다음 상태 또는 같은 출력 구조를 공유하면 높은 우선순위를 가진다.

절차 감각:

1. Reset state를 단순 code로 둔다.
2. 높은 우선순위 adjacency를 먼저 만족한다.
3. 남은 state를 K-map에서 grouping이 잘 되도록 배치한다.
4. 결과 next-state map의 1들이 얼마나 잘 clustering되는지 확인한다.

## Partitioning

FSM을 programmable logic component에 mapping할 때는 하나의 칩에 모든 입력, 출력, product term이 들어가지 않을 수 있다. 이때 FSM을 여러 부분으로 나누는 partitioning이 필요하다.

Partitioning이 필요한 이유:

- 입력 pin 수 제한
- 출력 pin 수 제한
- flip-flop 수 제한
- product term 또는 LUT 자원 제한
- timing 또는 배선 복잡도 제한

## Idle State를 이용한 Partitioning

FSM을 부분 회로로 나누면 한 partition이 담당하지 않는 transition을 표현하기 위해 idle state를 도입할 수 있다. Idle state는 해당 partition이 active하지 않을 때 머무르는 상태이다.

슬라이드의 규칙 요지:

- Source state가 다른 partition으로 넘어가는 경우 idle state를 출발점처럼 변환한다.
- Destination state가 다른 partition에 있을 때 해당 partition의 idle state에서 목적 상태로 들어오도록 변환한다.
- 같은 source 또는 destination을 공유하는 여러 transition은 조건을 보존하도록 나눈다.
- Idle state에는 hold condition을 둬야 한다.

6-state up/down counter 예제에서는 두 개의 idle state를 도입해 제한된 building block으로 전체 sequence를 나누어 구현한다.

## 최적화의 균형

FSM 최적화는 하나의 숫자만 줄이는 문제가 아니다.

- State minimization은 flip-flop 수를 줄일 수 있다.
- State assignment는 조합논리 복잡도를 크게 바꾼다.
- One-hot은 flip-flop 수를 늘리지만 logic을 단순화한다.
- Partitioning은 작은 programmable block에 맞추지만 idle state와 추가 제어가 필요하다.

따라서 최종 목표는 state 수, bit 수, product term 수, delay, pin 수, 설계 변경 용이성을 함께 고려한 구현 가능성이다.
