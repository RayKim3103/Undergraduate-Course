## 핵심 요약

이 장은 상태를 저장하는 순차논리를 다룬다. 조합논리가 현재 입력만으로 출력이 정해지는 회로라면, 순차논리는 feedback과 memory element 때문에 과거 상태가 현재 출력과 다음 상태에 영향을 준다. 핵심 소자는 latch와 flip-flop이며, 이들을 안전하게 연결하려면 clock, setup time, hold time, propagation delay, clock skew, metastability를 이해해야 한다.

장 전체의 흐름은 다음과 같다.

- Feedback으로 state가 생기는 원리를 이해한다.
- R-S latch, gated latch, master-slave latch, J-K flip-flop, D flip-flop을 비교한다.
- Clocking event 주변의 setup/hold timing 제약을 이해한다.
- Edge-triggered flip-flop을 cascade할 때 올바른 clock period 조건을 세운다.
- Asynchronous input이 synchronous system에 들어올 때 metastability와 synchronizer 문제가 생긴다.
- Register와 shift register를 상태 저장 블록으로 사용한다.

## 순차논리와 상태

순차회로는 feedback을 포함하고, 그 feedback 때문에 회로 내부에 state가 생긴다. State는 회로가 기억하고 있는 값이며, 조합논리의 입력이면서 동시에 출력처럼 다음 계산에 영향을 준다.

가장 단순한 기억 회로는 두 inverter를 서로 물린 구조다. 한쪽 값이 정해지면 반대쪽이 보수가 되고, 다시 원래 쪽으로 feedback되어 전원이 유지되는 동안 값을 보존한다. SRAM cell도 이러한 정적 저장 원리를 확장한 예로 이해할 수 있다.

## R-S Latch

Cross-coupled NOR 또는 NAND gate로 R-S latch를 만들 수 있다. NOR 기반 latch에서는 `S=1`이 set, `R=1`이 reset 역할을 한다. NAND 기반 latch에서는 active-low 입력인 `S'`, `R'`로 동작하므로 해석할 때 극성에 주의해야 한다.

R-S latch의 기본 동작:

- Set: Q를 1로 만든다.
- Reset: Q를 0으로 만든다.
- Hold: 이전 상태를 유지한다.
- Forbidden 또는 race 상태: set과 reset이 동시에 활성화되어 결과가 불안정해지는 경우다.

NAND 기반 R-S latch의 characteristic equation은 다음과 같은 형태로 정리된다.

```text
Q(t + delta) = S + R' Q(t)
```

여기서 현재 상태 `Q(t)`와 입력이 함께 다음 상태를 결정한다는 점이 순차논리의 핵심이다.

## Race Condition과 관측 동작

이론적으로 R-S latch의 금지 입력 상태를 생각할 수 있지만, 실제 회로에서는 두 입력이 완전히 동시에 변하지 않는다. 한쪽 신호가 먼저 바뀌면 latch가 어느 한 안정 상태로 떨어지고, 그 결과가 입력 경로에 다시 영향을 준다. 따라서 금지 상태에서 빠져나올 때 어느 상태가 될지 비결정적일 수 있다.

설계에서는 이런 입력 조합을 만들지 않도록 하거나, 입력 제약을 걸어 latch가 hold/set/reset의 의미 있는 상태만 사용하도록 만든다.

## Gated R-S Latch와 Clock

Gated latch는 enable 또는 clock 신호가 활성화될 때만 입력이 저장 소자에 영향을 주도록 만든다. Clock은 주기적인 timing reference이며, period와 duty cycle을 가진다.

Clock을 쓰는 이유는 입력이 충분히 안정될 시간을 기다린 뒤 저장 소자에 반영하기 위해서다. 하지만 level-sensitive latch를 단순히 여러 개 이어 붙이면 clock이 활성인 동안 값이 여러 latch를 통과하는 문제가 생길 수 있다.

## Cascading Latches와 Master-Slave 구조

Latch를 cascade할 때 같은 polarity의 clock으로 동시에 열리면 입력 변화가 여러 stage를 한 번에 지나갈 수 있다. 이를 막기 위해 서로 반대 polarity로 동작하는 master-slave 구조를 사용한다.

Master-slave latch는 master stage가 clock의 한 level에서 입력을 sample하고, slave stage가 반대 level에서 출력을 갱신한다. 이 구조는 feedback path를 clock phase로 끊어 순차 동작을 안정화한다.

## J-K Flip-Flop

J-K flip-flop은 R-S latch의 금지 상태 문제를 줄이기 위해 output feedback을 사용한다. 입력 조합에 따른 의미는 보통 다음과 같다.

- `J=0, K=0`: hold
- `J=1, K=0`: set
- `J=0, K=1`: reset
- `J=1, K=1`: toggle

J-K 구조는 유연하지만 입력과 feedback 경로가 복잡하고 timing 문제가 생길 수 있으므로, 실제 설계에서는 D flip-flop이 더 널리 쓰인다.

## D Latch와 D Flip-Flop

D latch/flip-flop은 set과 reset 입력이 동시에 활성화되는 문제를 피하기 위해 `S`와 `R`이 서로 보수가 되도록 만든다. 저장하려는 값은 하나의 입력 `D`로 제공되고, clocking event에서 그 값이 저장된다.

D flip-flop의 핵심은 clock edge 직전에 D가 안정되어 있어야 하고, edge 직후에도 일정 시간 유지되어야 한다는 점이다. 이 시간 창을 어기면 저장 값이 잘못되거나 metastability가 생길 수 있다.

## Setup Time, Hold Time, Propagation Delay

Clocking event 주변에는 입력이 변하면 안 되는 timing window가 있다.

- Setup time `Tsu`: clock edge 전에 입력이 안정되어 있어야 하는 최소 시간
- Hold time `Th`: clock edge 후에도 입력이 유지되어야 하는 최소 시간
- Clock-to-Q propagation delay: clock edge가 들어온 뒤 Q 출력이 바뀌기까지 걸리는 시간
- Minimum clock width: clock pulse가 저장 소자를 제대로 동작시키기 위해 필요한 최소 폭

Edge-triggered D flip-flop의 timing specification은 대부분 rising edge 또는 falling edge 기준으로 측정된다.

## Reset과 Set 기능

Flip-flop에는 reset 또는 set 기능이 추가될 수 있다.

Synchronous reset:

- 다음 clock edge에서만 상태가 reset된다.
- timing 분석이 clock 기준으로 통일된다.
- 느리지만 예측 가능하다.

Asynchronous reset:

- clock을 기다리지 않고 즉시 상태를 reset한다.
- 빠르지만 clock domain과 무관하게 상태를 바꾸므로 timing 위험이 있다.

디지털 시스템에서는 빠른 초기화가 필요한 경우 asynchronous reset을 쓰더라도, 해제 시점은 synchronous하게 맞추는 방식이 자주 필요하다.

## Timing Methodology

Timing methodology는 저장 소자와 조합논리를 안전하게 연결하는 규칙이다. Edge-triggered flip-flop 기반 시스템에서는 한 flip-flop의 출력이 clock edge 후 변하고, 조합논리를 거쳐 다음 flip-flop의 입력에 도착한 뒤, 다음 clock edge 전에 setup time을 만족해야 한다.

기본적인 clock period 제약:

```text
Tclk >= Tclk-to-Q(max) + Tcomb(max) + Tsetup + Tskew_margin
```

Hold 제약은 너무 빠른 경로에서도 문제가 생길 수 있음을 보여준다.

```text
Tclk-to-Q(min) + Tcomb(min) >= Thold + skew_effect
```

즉 회로는 너무 느려도 실패하지만, 특정 경로가 너무 빨라도 hold violation이 생길 수 있다.

## Clock Skew

Clock skew는 같은 clock 신호가 여러 flip-flop에 서로 다른 시간에 도착하는 현상이다. 고성능 시스템에서는 배선 길이, buffer tree, load 차이 때문에 skew가 무시할 수 없어진다.

Clock skew가 크면 다음 문제가 생긴다.

- 어떤 flip-flop은 먼저 sample하고 다른 flip-flop은 늦게 sample한다.
- 예상보다 짧은 시간 안에 데이터가 다음 stage에 도달해야 할 수 있다.
- 반대로 데이터가 너무 빨리 도착해 hold time을 위반할 수 있다.

따라서 synchronous system은 clock distribution까지 설계 대상에 포함해야 한다.

## Asynchronous Input과 Metastability

Synchronous circuit은 clock 기준으로 입력, 상태, 출력을 sampling한다. 하지만 외부 버튼, 다른 clock domain, 비동기 통신 신호처럼 clock과 무관하게 변하는 입력이 들어오면 setup/hold time을 위반할 수 있다.

이때 flip-flop 출력이 0도 1도 아닌 중간 상태에 잠시 머무르는 metastability가 발생할 수 있다. 확률은 작지만 0이 아니며, 완전히 제거할 수 없다. 일반적인 완화책은 synchronizer를 사용해 비동기 입력을 두 개 이상의 flip-flop stage를 거쳐 내부 clock domain으로 가져오는 것이다.

## Synchronous System의 한계와 Handshaking

매우 큰 시스템에서는 전체를 하나의 완벽한 clock으로 묶기 어렵다. Clock skew와 long wire delay가 커지기 때문이다. 이를 완화하기 위해 locally clocked subsystem을 두고 request/acknowledge signaling으로 통신할 수 있다.

4-cycle return-to-zero protocol:

1. Master가 request를 올린다.
2. Slave가 작업을 수행하고 acknowledge를 올린다.
3. Master가 데이터를 latch하고 request를 내린다.
4. Slave가 acknowledge를 내린다.

2-cycle non-return-to-zero protocol은 request와 acknowledge의 level 변화 자체를 새 이벤트로 해석한다. 추가 상태가 필요하지만 transition 수를 줄일 수 있다.

Self-timed circuit은 외부 clock 없이 자신이 작업 완료 시점을 판단한다. 보통 worst-case delay를 모델링한 delay line을 사용해 완료 신호를 만든다.

## Register와 Shift Register

Register는 여러 flip-flop을 묶어 여러 bit 값을 저장하는 블록이다. Shift register는 clock마다 값을 한 칸씩 이동시키며, serial/parallel 변환에 활용된다.

Universal shift register는 보통 다음 기능을 가진다.

- Hold state
- Shift right
- Shift left
- Parallel load

각 cell은 MUX와 D flip-flop으로 구성할 수 있다. Select 신호가 어떤 입력을 D로 보낼지 선택하고, clock edge에서 그 값이 저장된다.

Shift register 응용:

- Parallel-to-serial conversion
- Serial-to-parallel conversion
- Delay line
- Counter 또는 sequence generator의 기본 블록
